# Sonora Player — план разработки

## Принципы
- Локальные файлы пользователя и легальные источники.
- Без рекламы и трекинга по умолчанию.
- Не обходить DRM и не использовать нелегальные каталоги/API.
- Сканирование и индексирование не должны блокировать UI.
